Dabao Agent 2.0 启动说明
==========================

一、正常启动

直接双击：

启动大宝Agent.bat

启动后会出现一个蓝色或黑色窗口，这是运行日志窗口，请保持它打开。
大约几秒后，默认浏览器会自动打开 Dabao Agent 工作台。

正常工作台地址：
http://localhost:8501


二、正常启动打不开时

如果提示端口被占用，或者浏览器打不开正常地址，请先关闭原来的启动窗口，然后双击：

启动大宝Agent-备用端口.bat

备用工作台地址：
http://localhost:8502


三、如何停止

直接关闭显示运行日志的蓝色或黑色窗口，Dabao Agent 就会停止。
关闭浏览器页面不会停止程序。


四、常见提示

1. 提示“未找到 Python 虚拟环境”
   说明项目根目录中缺少 .venv 文件夹，或者首次安装还没有完成。

2. 提示“未找到 app.py”
   说明启动文件不在正确的项目根目录。请确认启动文件与 app.py 放在同一个文件夹中。

3. 浏览器没有自动打开
   保持运行日志窗口不要关闭，然后手动在浏览器地址栏输入：
   http://localhost:8501
   备用版本输入：
   http://localhost:8502

以后启动 Dabao Agent，不需要打开 PowerShell，不需要激活虚拟环境，也不需要输入 Python 或 Streamlit 命令。
